# Website for one of the user's apps

This repository is **public**, and GitHub Pages publishes it. Never add notes,
internal details or anything private to it.

The shared rules for all the user's projects are in the private repository
`github.com/joeldubey/claude-shared`. In a cloud session, clone it
(`git clone https://github.com/joeldubey/claude-shared ../claude-shared`) and
read its `CLAUDE.md` and `memory/` before starting. Every URL these pages give
a user is the app's own `<app>.dubayaapps.com` address (rule #28 there).
